MADE FOR YOUR EVERYDAY

One app. More possibilities.

ချိတ်ဆက်မှုကနေ စိတ်ကြိုက် settings အထိ — သင်လိုအပ်တဲ့ လုပ်ဆောင်ချက်တွေကို တစ်နေရာတည်းမှာ အသုံးပြုပါ။

01

Multiple protocols

SSH၊ OpenVPN၊ V2Ray၊ UDP Hysteria နဲ့ Slow DNS တို့မှ မိမိအသုံးပြုလိုတဲ့ protocol ကို ရွေးချယ်နိုင်ပါတယ်။

02

Custom DNS & server

DNS နဲ့ server ကို မိမိချိတ်ဆက်မှုအတွက် လိုအပ်သလို သတ်မှတ်ပြင်ဆင်နိုင်ပါတယ်။

03

Import configuration

Config file သို့မဟုတ် ကူးယူထားတဲ့ configuration ကို import လုပ်ပြီး ချိတ်ဆက်မှုကို စီစဉ်နိုင်ပါတယ်။

04

Make it yours

App colors နဲ့ settings တွေကို သင့်စိတ်ကြိုက် ပြင်ဆင်ပြီး ကိုယ်ပိုင်အသုံးပြုမှုပုံစံ ဖန်တီးပါ။

05

Custom network

Custom network options တွေနဲ့ သင့် network အတွက် လိုအပ်တဲ့ setting တွေကို ချိန်ညှိနိုင်ပါတယ်။

06

Update configuration

App ထဲက Update Config လုပ်ဆောင်ချက်နဲ့ configuration ကို ပြန်လည် update လုပ်နိုင်ပါတယ်။

A few things to know.

SVPN ကို ဘယ်လို download လုပ်ရမလဲ?

Download ခလုတ်ကို နှိပ်ရင် Google Play ရဲ့ SVPN Connect စာမျက်နှာကို ဖွင့်ပေးပါမယ်။ အဲဒီမှာ Install ကိုနှိပ်ပြီး ထည့်သွင်းနိုင်ပါတယ်။

ဘယ် protocol တွေကို support လုပ်သလဲ?

SSH၊ OpenVPN၊ V2Ray၊ UDP Hysteria နဲ့ Slow DNS တို့ကို support လုပ်ပါတယ်။ ချိတ်ဆက်နိုင်မှုက အသုံးပြုတဲ့ server၊ configuration နဲ့ network ပေါ်မူတည်ပါတယ်။

Download နှိပ်သူအရေအတွက်က ဘာကို ရေတွက်ထားတာလဲ?

လက်ရှိမှာ ဤ browser မှ Download ခလုတ်ကို နှိပ်ထားခြင်းကို ရေတွက်ထားပါတယ်။ တူညီတဲ့ browser မှ ထပ်နှိပ်ရင် ထပ်မတိုးပါ။ Visitors အားလုံးရဲ့ စုစုပေါင်းမဟုတ်သလို Play Store မှာ app install ပြီးသူ အရေအတွက်လည်း မဟုတ်ပါ။
